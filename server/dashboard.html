Soil ADC readings are shown even if the 0–100 moisture index is not yet calibrated. These are not soil-moisture percentages.

Health uses original readings, before missing values are filled from older records. REPORTING means a recent value is in range; it does not prove accuracy. For soil probes, REPORTING confirms an ADC signal only; verify dry/moist response separately. Calibration status is shown in its own column.

Check each sensor physically

Wait for a new five-minute sample after each test. DS18B20: gently warm the probe and look for a gradual temperature rise. DHT22: compare temperature and humidity with a reference meter. BH1750: cover the sensor, then uncover it; lux should fall and rise. Soil probes: compare air/dry soil with moist soil; ADC should change clearly. Keep connectors and electronics out of water. Measure dry and wet endpoints separately for each probe to calibrate.

DELAYED means the sample is older than seven minutes, or its clock is invalid. A power failure may stop all reports without sending an error. Check Serial Monitor for brownouts. A node with no records cannot report sensor health.

Validation, missing values and calibration

The backend keeps raw sensor JSON separately from cleaned data. "WARN" may mean soil probe calibration is not configured, even when temperature, humidity and lux are valid.

How readings reach the cloud

The ESP32 sends a reading every five minutes over verified HTTPS. It keeps queued readings in flash until the server confirms their record ID. During an internet outage, the table shows saved history and warns when measurements are delayed. Stable power is still required.

This dashboard is public. Every visitor can reveal and copy this read-only key. It cannot upload device measurements.
curl.exe "https://naimiris.flameswp.site/api.php?route=c1/realtime" -H "X-API-Key: YOUR_READ_KEY"
Send your separate read key in the X-API-Key request header. Add &node_id=NODE_01 or &node_id=NODE_02 for one device. Returns the latest stored raw readings and sensor health, with sample age and a delay flag. Refreshing this API does not trigger a new sensor measurement. Sampling remains every five minutes. Provisional moisture is returned separately as estimated_moisture_index; calibrated_moisture_index stays null until measured calibration is set.
Use Copy full request to get a ready-to-run command. Opening the API URL alone does not send the required X-API-Key header. Existing dashboard data and export routes remain public.
