# Individual research experiments

Use separate component directories (**c1**, **c2**, **c3**, **c4**) for actual
research algorithms, notebooks, model training, reproducible tests and analysis.
Each component owner creates and organises their own files.

The existing C2 learning and synthetic practice code remains on its own
feature branch until the team agrees a migration. Practice or synthetic results
must not be described as validated field outcomes.

Do not commit private farm records, large model weights, or datasets that
cannot legally be redistributed.
