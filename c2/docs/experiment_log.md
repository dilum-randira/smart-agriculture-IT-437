This file distinguishes completed learning exercises from field research experiments. Each future entry should include the date, objective, dataset source/version, targets and units, split method, model settings, observed metrics, limitations, and links to code or results.

## 2026-10-09 — Practice 01: supervised crop-yield regression

**Status:** completed educational exercise; **not** validated Nai Miris research.

- **Objective:** learn features (`X`), target (`y`), `fit()`, `predict()`, evaluation, and a simple reference baseline.
- **Environment:** Google Colab originally; reproducible Python version committed under `c2/practice/`.
- **Dataset:** 300 deterministic **synthetic** examples created from a deliberately invented formula; no field measurements, plot-linked harvest labels, or C1 sensor records.
- **Inputs:** simulated soil moisture, air temperature, relative humidity and crop age.
- **Target:** hypothetical yield (kg) generated by the practice formula.
- **Evaluation split:** random 80/20 split (`random_state=42`), appropriate here only for independent synthetic practice examples.
- **Models:** training-set mean (`DummyRegressor`) and Random Forest (100 trees, fixed seed).
- **Observed practice metrics:** mean reference MAE 0.8074, RMSE 0.9573, R² -0.0051; Random Forest MAE 0.3744, RMSE 0.4586, R² 0.7693. These are **synthetic practice** numbers, not crop prediction claims.
- **Reproducibility:** `python c2/practice/yield_regression.py`.
- **Checks:** `python -m unittest discover -s c2/tests -v`; two tests passed in a local verification run.
- **Limitations:** synthetic relationships were explicitly designed into targets; resulting performance cannot establish performance on real crops or new farms.
